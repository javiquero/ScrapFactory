# Arte en PNG

Recortado de una hoja generada con Gemini a partir del prompt de estilo del proyecto
(vista cenital con algo de perspectiva, pintado a mano, colores pastel apagados,
maquinaria oxidada y remendada). Fondo transparente real.

- `extractor`, `prensa`, `ensambladora`, `teletransportador`: máquinas. El juego les añade
  por código la animación (temblor, chispas, vapor, haz de luz).
- `junk_*`: piezas sueltas de los vertederos.
- `item_*`: objetos que viajan por las cintas.
- `extra_1` … `extra_5`: edificios que salieron de propina en la hoja; reservados para
  máquinas futuras (no se usan todavía).

Si un PNG falta, el juego usa el dibujo por código de `src/sprites/`.
