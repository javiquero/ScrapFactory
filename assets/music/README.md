# Música

Pistas de la colección **Open Lo-Fi** de Bilal Tahir (https://github.com/btahir/open-lofi),
publicadas en dominio público con licencia **CC0 1.0**: se pueden usar para cualquier cosa,
también comercial, sin atribución. Aun así lo dejamos apuntado.

| Archivo | Título original |
| --- | --- |
| soft-gold-sky.mp3 | Soft Gold Sky |
| window-seat-daydream.mp3 | Window Seat Daydream |
| porchlight-golden-hour.mp3 | Porchlight Golden Hour |
| dust-on-the-morning-keys.mp3 | Dust on the Morning Keys |

Recodificadas a 96 kbps y normalizadas a -18 LUFS (ffmpeg) para que pesen poco y suenen flojas.
Para cambiar o añadir pistas: copiarlas aquí y editar la lista `PISTAS` en `src/audio.js`.
